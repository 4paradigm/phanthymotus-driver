# Q5 ArUco 区域识别测试

此卡片把 RealMan 阶段的三区域 ArUco 逻辑放到 Q5 上验证。它复用 Q5 现有
`camera_rgb` 的 D455 JPEG 帧，不打开第二路相机，也不调用 Q5 运动接口。
图像来自 Q5 相机工作进程；带框预览和区域 JSON 通过媒体桥发布到画布使用的
ROS Domain 42。

更新 Q5 Driver 镜像并启动后，在画布中：

1. 添加并启动 `camera_rgb`，确认 RGB 画面正常。
2. 添加 `aruco_zones`，将 `camera_rgb` 的 `image/jpeg` 输出连接到它。
3. 在卡片配置中填写 `waiting_rect`、`sorting_1_rect`、`sorting_2_rect`，
   格式为 `x1,y1,x2,y2`，原点在画面左上角，四个数字均处于 0 到 1。
   例如横向三列：`0,0,0.3,1`、`0.35,0,0.65,1`、`0.7,0,1,1`。
4. 选择匹配实物码的 ArUco 字典；默认 `DICT_4X4_50`。颜色标签仅记录规划目标，
   当前不会识别物体颜色。
5. 在相机画面中放入三个不同 ID 的码，确认带框预览和区域 JSON。
   每个区域恰好包含一个码中心，且三个 ID 不同时，JSON 的 `ready` 为 `true`。
   移走一码或把两个码放入同一区域，应变为 `false`。

`info` 返回最近一次识别结果、错误及帧龄；停止画面超过 3 秒后，
`info.latest.ready` 会变为 `false`。这里只验证图像坐标区域，不进行相机到
机械臂的坐标标定，也不执行抓取。Q5 摄像头会随头部移动；测试期间应保持相机视角固定。
