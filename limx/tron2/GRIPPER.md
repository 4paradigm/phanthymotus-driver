# TRON2 左右夹爪卡片

在Motus分别使用`gripper_left`（左夹爪）和`gripper_right`（右夹爪）。每张卡片固定对应一侧，无需选择SIDE，动作顺序为open、close、recover。

| 操作 | 用途 | 填写参数 |
|---|---|---|
| open | 调整本侧开口大小 | opening_mm（0至85mm）、speed、force |
| close | 闭合至最小开口 | speed、force |
| recover | 检查静止反馈后恢复本侧失败任务 | 无 |

## 开口输入与单位

从0.6.7起，客户填写的字段是`opening_mm`，单位毫米（mm），表示两指间的目标开口大小。0mm为最小闭合，85mm为当前最大目标。字段没有默认值，open必须明确填写；speed和force也不自动预填。

按用户确认的名义线性关系，驱动自动换算：

`底层目标 = opening_mm × 94 / 85`

| 毫米输入 | 底层目标 |
|---|---|
| 0 | 0 |
| 40 | 44.235294 |
| 42.5 | 47 |
| 85 | 94 |

底层值保留至小数点后6位。厂家可能将反馈量化；到位仍使用原有底层误差不超过1档、至少3次更新时间戳反馈且稳定至少0.5秒的判断，没有扩大容差。1个底层档位按此映射约为0.904mm，这不是厂家承诺的实际定位精度。

此关系采用标称最大夹持宽度85mm和当前控制上限94建立，是软件名义换算，尚未完成实际间距标定。不得把返回的毫米估计当作独立距离传感器读数或精确实测。厂家原始反馈`opening`仍按0至100读取，不截断、不缩放原始字段；`opening_mm_estimate`为计算值，超出配置范围时也不静默夹到85。

旧的`opening`参数已经停用。新的open收到该字段会明确拒绝，即使同时提供opening_mm也不会执行。请刷新卡片重新填写毫米输入；不会把旧值50自动当作50mm，也不会把旧100静默改成85mm。close、recover和只读/生命周期操作可以忽略旧网页残留的opening，避免隐藏字段阻碍非open操作。未知字段仍拒绝。

`open`请求示例（左、右卡片同样参数）：

```json
{"action":"open","opening_mm":40,"speed":10,"force":10}
```

响应的`target_opening_mm`保留客户填写的毫米目标，`target_opening_raw`显示发给厂家的值；为兼容历史任务，`target_opening`仍是底层单位。完成结果另有`reported_opening_mm_estimate`。`opening_mapping`说明名义换算方法，`opening_mm_is_calibrated=false`说明并非已标定实测。

## 速度、力和抓持结果

speed仍是大于0至100的相对速度档位，force仍是0至100的相对力档位。毫米换算不改写这两项。force不能直接当作牛顿，也不能仅根据标称20N推断force10等于2N；当前接口未提供已校准的力/压力测量说明。

达到目标开口不代表抓取成功，返回始终`grasp_verified=false`。关闭时物体使夹爪停在非零开口，当前驱动仍不能自动判为成功夹持；接触检测、真实力反馈和夹持完成语义需另行开发。

## 完成、恢复与连续操作

动作响应“已受理”不等于物理动作已经完成；真实完成通过ACP回调报告。每次只向所选侧发送opening/speed/force，不给另一侧填默认值。左、右独立跟踪任务、反馈、回调和恢复，但断连或厂家全局故障仍可能影响两侧。

已在目标开口时，只验证新反馈、稳定开口和零速度，不重复写电机，结果为no_op=true、motion_sent=false。超时、回执不明或厂家错误不会自动重发；实际发过指令而结果未确认时，本侧保留保护。recover前须现场确认本侧静止空载、周围无手或障碍物；恢复检查原连接下至少3次更新反馈、至少1秒开口稳定且速度零，并确认原ACP结果已通知平台。恢复不是急停，不会开合，不把原失败改为成功，也不能判断现场是否有人或夹持物体。

每侧最多允许一条后续指令等待实际前序任务结束或恢复结束，无固定冷却时间，等待上限40秒；超时、断连、取消或stop后不保留待发动作。先recover左再recover右不会撤销左侧恢复。

显式的新close可接替已确认厂家回执、但未达到目标的open。若连续新反馈已确认本侧停在非目标开口，且确有close等待，原open可提前按未到位失败结束，不必耗尽20秒窗口。原失败ACP送达后，仍须通过静止接替检查才发送一次close。未知回执、换连接、厂家故障或未确认的close不走此路径。原目标、反馈和失败保存在previous_action_error中；没有新close不自行关闭。

生命周期stop或关闭驱动会取消未受理的等待/接替请求，不会停止已发送的实体动作，也不声明硬件急停。

机械臂与夹爪任务互斥：夹爪处于张开位置本身不会阻止机械臂；夹爪任务执行中、恢复中、等待中或结果不明时会阻止机械臂动作。机械臂任务执行或结果不明时也阻止两侧夹爪。目标85mm对应反馈94并正常完成后，可以保持张开而解除这项互斥。原始自然垂下home和骨架固定夹爪轮廓不变。

## 验证范围

本地使用假机器人和真实回环HTTP/WebSocket，验证毫米换算、两侧独立控制、到位、ACP、失败保护、参数切换、重复操作、恢复及机械臂互斥。部署只验证源码、schema、状态、生命周期、恢复空操作、关节和视频，不自动执行实体开合或机械臂动作。实际毫米精度和抓取性能由现场另行验证。
