# S10 front depth: bounded two-dimensional filling

Goal: reduce the scanline lattice and increase coverage on the captured S10
clouds while keeping one automatically configured output. No deployment or
robot configuration changes are part of this work.

Design: replace independent row/column lines with two fixed interpolation
paths: horizontal then vertical, and vertical then horizontal. The second
stage may use first-stage segments, each supported by original measurements;
carry their original minimum/maximum depths through both stages. There is no
iteration, extrapolation or reuse across frames. Each bracket has at most 16
missing pixels. All contributing originals must agree within both 150 mm and
6% of the nearest depth. Reject path disagreements exceeding both the existing
60 mm / 2% agreement rule (threshold is the smaller bound). Preserve every
measured pixel, uint16 millimetres, unknown zero and LiDAR timestamps.

This is my implementation choice within the requested coverage improvement.
Simply widening one-dimensional lines retains the lattice. Learned/RGB-guided
or temporal filling adds dependencies and alignment/motion assumptions that the
current inputs cannot support. The two-dimensional method makes bounded small
patches using the existing measured samples. NumPy is already present on the
inspected Jetson; declare the dependency for future builds.

1. Add failing surface-interior, sloped-surface, support-range and no-growth
   tests; retain discontinuity, conflict, measured-value and invalid-packet tests.
2. Implement the two fixed paths using bounded NumPy arrays; keep the function
   signature/stats and single-output worker unchanged. Update metadata/docs.
3. Replay all three captured clouds against baseline/new fill, verify measured
   values and unknown borders, create comparison images and record coverage.
   Measure computation in an isolated read-only Jetson process if reachable;
   never start the business card or publish ROS messages.
4. Run projection and relevant S10 integration tests, then the repository test
   command; report any pre-existing collection/environment failures. Review the
   patch for discontinuity crossing, overflow, memory and output regressions.

Success: higher same-frame coverage with filled two-dimensional interiors,
preserved originals, bounded support and rejected inconsistent surfaces. A
denser estimate does not establish free space, measured depth accuracy or
synchronized RGB-D. Hardware deployment and full reprojection remain pending.
