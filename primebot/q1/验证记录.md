## 隔离集成测试

`tests/test_battery.py` 使用本地 BMS 发布者，分别在域 87、88 验证厂商接口、跨域输出、数值换算、无样本、停止输出、过期数据与重新启动。测试不需要连接机器人。在驱动仓库根目录运行：

```bash
docker run --rm --network none \
  -v "$PWD/primebot/q1/tests:/work/primebot/q1/tests:ro" \
  primebot-q1:local bash -ec 'source /opt/ros/humble/setup.bash && source /q1_ws/install/setup.bash && /usr/bin/python3 /work/primebot/q1/tests/test_battery.py'
```

## 原 status 卡的 ARM64 一键启停

2026-11-23 在同一台 Apple 芯片 Mac 上通过 Docker Desktop 和网线验证。`build` 使用 ROS 官方 Humble 镜像编译了 ARM64 driver，公开基础镜像构建出的 driver 通过隔离集成测试。

- `stop` 结束 macOS DDS 进程并移除 Q1 的 driver 和 UDP 转发容器，Core 保持健康。
- `start` 恢复三项服务。再次执行 `start` 复用原实例，Core 只注册一个 Q1 MCP 地址。
- Core 启动 `status` 卡片后，画布使用的 WebSocket 于 11:19:08–11:19:10（UTC+8）连续收到六帧 `live` 电池数据。最后一帧为 SOC 32%、电压 44.63 V、电流 −1.48 A、功率 64.267 W、循环 1 次、温度 32 °C。

## 部署与验证范围

- Mac 真机验证使用同一台 Mac 上的 Core 与 Q1 driver。Linux ARM64 采用同一主机上的 Core 与 driver，Jetson／板载机的真机验收需要相应设备。
- Mac 一键入口在当前已登录的 macOS 用户会话中启动 DDS 转发。默认使用有线地址 `10.1.1.99`，占用有线 UDP 17810、17811 和本机回环 UDP 17812、17813。已有旧版手工转发或 Q1 容器时，切换前需先停止旧实例。
- 刚启动时 `status` 可能显示 `waiting`。连线后持续缺少电池数据时，检查 Mac 有线地址和 `primebot/q1/.runtime/dds.log`。容器日志用 `docker logs primebot-q1-driver-1` 与 `docker logs primebot-q1-ingress-1` 查看。
