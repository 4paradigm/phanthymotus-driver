# Bumi 场景 Skill 源码

这里保存机器人运行时 Skill，随 `feat/bumi-driver` 管理版本。
这些目录不会因为构建驱动镜像而自动安装到 Agent Core；Skill 按 landing 文档通过技能广场的“我的技能”单独创建、安装和提交审核。

| 目录 | 内容 | 当前状态 |
|---|---|---|
| `bumi-person-wave` | 持续看到人后挥手并说“您好，欢迎光临！” | 已有程序与历史单次实机触发、语音确认；完整场景仍需验收 |
| `station-photo-inspection` | 指定工位拍一张照片并返回真实路径与时间 | 定义和独立拍照链路已有检查；模型驱动场景仍需验收 |
| `bumi-foot-rps` | 脚部石头剪刀布规则、解析与比分 | 开发草稿，仅离线规则；未提供可安装 Skill |

Card 的代码交付走驱动 PR 与测试镜像流程。Skill 的交付走技能广场：

1. 在“我的技能”创建草稿，按各目录的 `skill.json` 填写名称、简介、指令与依赖。
2. 有随附文件的技能，上传清单中声明的原始文件；文件字节数与 SHA-256 必须一致。
3. 安装到目标机器人，由操作者手动配置必要画布连接。
4. 修改已安装版本后按当前页面的卸载、重新安装流程更新，先停止该技能运行中的任务。
5. 完成 Master 与老师验收后提交审核，保留已发布或验收截图。

`package_skill.py`、`install_skill.py` 和 `deploy.py` 是保留的开发／应急入口，只有主动执行才会修改设备。
默认使用网页管理。直接 API 测试不等于 Agent 已按 Skill 完成任务，代码在 Git 分支中也不等于技能已发布。

本次迁移只运行本地检查，没有安装、启动技能或操作机器人。
实时状态、认证信息、照片与旧安装备份不进入 Git。
