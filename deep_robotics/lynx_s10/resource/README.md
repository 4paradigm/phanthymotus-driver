# S10 resources

`S10.urdf` is the official S10 model used by the joints card.

For local offline builds, keep `deep-robotics-msg-a0d1a29eec5c4db5a9107595bb51e3be8122b86c.zip` in this directory. The archive is intentionally ignored by Git. Docker builds download the same pinned upstream revision and verify SHA-256 `1d268a76e80af8ea5aa3dc28de0c236de87bce55a5d397fdad1e23515f02a537` before building `drdds`.
