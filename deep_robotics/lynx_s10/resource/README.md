# S10 resources

`S10.urdf` is the official S10 model used by the joints card.

`deep-robotics-msg/` contains the upstream `drdds` ROS message source at revision `a0d1a29eec5c4db5a9107595bb51e3be8122b86c`. It is included as source files so Docker builds do not depend on GitHub availability. The local ZIP archive is ignored by Git; its SHA-256 is `1d268a76e80af8ea5aa3dc28de0c236de87bce55a5d397fdad1e23515f02a537`.
