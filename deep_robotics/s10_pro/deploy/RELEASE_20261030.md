# S10 offline development release — 2026-10-30

Branch: `feat/s10-offline-acp-20261030`, targeting upstream `main`.
This version carries the S10 implementation from PR #451 at `98d734f2` and
integrates upstream `main` at `07f0e55c95a06a54d588c947c2d25d19c058d61a`.
It is a replacement review candidate; the original PR is not closed or changed.

## Changes since PR #451

- Accept the exact legacy Core `{ok: true, action_id}` receipt as endpoint
  acceptance so a successful callback is not retried. This does not claim that
  the legacy endpoint caches or deduplicates callbacks after a lost response.
  Modern receipts still require a valid matching action ID and receipt state.
- Expose `sitdown` while retaining `stand_down` for saved canvases. The operation
  continues to use the existing lie-down controller and feedback requirements.
- Return concise locomotion status, results and ACP payloads. Preserve protocol
  identifiers and failure fields; retain full evidence through `info` and the
  durable task store. Accepted commands explicitly tell callers to wait for ACP.
- Log repeated automatic Prepare blockers only when the meaningful outcome
  changes; preserve preparation, authorization and stopping behavior.
- Verify the historical G1 reference against its recorded Git tree and hashes,
  allowing current upstream G1 files to evolve without reverting them.

## Validation boundaries

The release gate is listed in `scripts/s10_pr_tests.txt`; it is a selected offline
regression set, not the entire repository suite. The final run passed 683 tests
with 1 skipped in 63.26 seconds. Tests use synthetic feedback and a local TLS
server. Catalogue/schema/Docker COPY checks and the service checker also passed.
The historical monitor catalogue and manual Prepare tests still require
migration as documented in `UPDATE_PR.md`.

No robot connection or deployment is part of this release. ARM64 image startup,
physical acceptance, actual CPU use and legacy Core end-to-end behavior remain
to be validated with hardware. The new branch was prepared in an independent
checkout; the source checkout's uncommitted changes were preserved.
