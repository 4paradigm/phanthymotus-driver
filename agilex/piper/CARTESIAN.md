# PiPER 机械臂末端空间移动卡片

支持读取 SDK End Pose，并预览保持姿态下沿基座 X/Y/Z 轴移动 0.1–20 mm；默认 +5 mm。局部逆解匹配现场 DH 模型、限位与奇异姿态。41 个样本检查预测关节路径；执行期间核对实际末端反馈。复用共享许可、预览确认、操作锁和停止。

使用现有低速关节插补，不能保证严格直线或避障；末端参考点没有自定义工具偏移。仅在模拟机械臂验证，实机展示须另行进行。

此增量基于同事 PiPER 基础分支提交 `f5ca598278a3f015cd9503d674a81d2d75b122fa`（PR #382），增加一张卡片，不包含关节限位 PR #386 或实时角度 PR #387。
