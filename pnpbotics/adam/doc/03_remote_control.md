# 遥控说明

> Source: https://wiki.pndbotics.com/robot/remote_control/

## 模式定义

| 概念 | 说明 |
|------|------|
| 阻尼模式 | 机器人所有关节停止主动运动，停留在当前位置，摆动时有明显阻尼感 |
| 零位模式 | 机器人所有关节运动到固定位置并锁定 |
| 站立模式 | 机器人进入站立状态，可以控制机身的横滚、俯仰、偏航方向的姿态以及高度；可执行预定动作、开启遥操或数据记录等功能 |
| 行走模式 | 机器人进入行走状态，可以控制机器人的行走和旋转速度 |
| 跑步模式 | 机器人进入跑步状态，可以控制机器人的跑步和旋转速度 |
| 开发者模式 | 推荐由阻尼模式进入，用于SDK开发，该模式下可接收用户控制数据，实现自定义控制 |

## RCU指示灯说明

RCU指示灯位于机器人正面胸口电池盖下方。

| 模式状态 | 颜色 |
|----------|------|
| RCU启动成功，未连接NUC | 紫色快速呼吸 |
| RCU启动成功，已连接NUC | 紫色慢速呼吸 |
| 开发者模式 | 蓝色慢速呼吸 |
| 电量低 | 红色快速呼吸 |
| 电池未连接 | 红色慢速呼吸 |
| 零位检查异常 | 黄色常亮 |
| 执行器异常 | 黄色慢速呼吸 |
| 绝编异常 | 黄色快速呼吸 |

## 操作说明

| 模式 | 按键 | 前序状态 | 功能描述 |
|------|------|----------|----------|
| **阻尼模式** | LT + B | 任意模式 | 任何模式可进入，用于安全停止动作或进入**开发者模式** |
| **零位模式** | A | 阻尼/站立 | 进入**零位模式**，所有关节运动到固定位置并锁定 |
| **站立模式** | X | 零位/行走 | 进入**站立模式**，可执行预定动作、开启遥操或数据记录等功能 |
| | RB | 站立 | 执行单个预设动作 |
| | 左摇杆水平方向 | 站立 | 控制机器人机身横滚方向姿态 |
| | 左摇杆竖直方向 | 站立 | 控制机器人机身俯仰方向姿态 |
| | 右摇杆水平方向 | 站立 | 控制机器人机身旋转方向姿态 |
| | 右摇杆竖直方向 | 站立 | 控制机器人机身高度 |
| | 十字键 → | 站立 | 开启遥操接收模式 |
| | 十字键 ← | 站立 | 退出遥操接收模式 |
| | RT + 十字键 ↓ | 站立 | 触发数据记录开始/结束，记录全部关节+手指位置数据。记录地址：`/etc/pndbotics/pnd_adam_dds`，播放地址：`/etc/pndbotics/pnd_adam_dds/Sources/motion` |
| | X | 行走 | 由**行走模式**切回**站立模式** |
| **行走模式** | Y | 站立/跑步 | 由**站立模式**进入**行走模式**，可以通过摇杆控制机器人的行走和旋转速度 |
| | 左摇杆竖直方向 | 行走 | 控制机器人前进、后退速度 |
| | 右摇杆水平方向 | 行走 | 控制机器人偏航角度速度 |
| | 十字键 | 行走 | 控制机器人侧向位置补偿 |
| | RB | 跑步 | 由**跑步模式**切回**行走模式** |
| **跑步模式** | RB | 行走 | 由**行走模式**进入**跑步模式**，可以通过摇杆控制机器人的跑步和旋转速度 |
| | 左摇杆竖直方向 | 跑步 | 控制机器人前进、后退速度 |
| | 右摇杆水平方向 | 跑步 | 控制机器人偏航角度速度 |
| | 十字键 | 跑步 | 控制机器人侧向位置补偿 |
| **开发者模式** | LO + RO | 阻尼 | 由**阻尼模式**可进入，接收用户控制数据，实现自定义控制 |
| | LT + B | 开发者 | 退出用户控制，切回**阻尼模式** |
| **执行器下电** | LB + RB | 任意模式 | 紧急情况可按下立即断电 |

## 配对连接

出厂设置默认已配对，开机自动连接。若需更换手柄重新配对，参考以下步骤：

1. 浏览器输入机器人IP：`192.168.XX.XX`（手柄背面获取）进入PAC界面
2. 长按手柄**配对键**至指示灯快速闪烁
3. 点击"无线设置"，在"可用设备"一栏找到设备名称"Xbox Wireless Controller"，点击进行配对连接
