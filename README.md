# G1 颁奖典礼主持 Skill

Unitree G1（上海，`10.110.12.110`）的**颁奖典礼主持 Skill**。机器人只负责念词、带气氛、
揭晓与庆祝，**不递送实物、不代领奖品**。

- Skill 唯一标识：`g1-award-ceremony`
- 当前版本：`2.0.0`
- 名称：`G1 颁奖典礼主持`
- 依赖工具（已被 G1 driver 提供）：`tts`、`arm`、`loco`、`led`
- 画布地址：`https://10.110.12.110:15678/`（HTTPS，自签证书，浏览器需选择「继续访问」）

## 一、颁奖仪式步骤（机器人执行流程）

整场典礼由主持人在画布 `remote_message` 用**文字指令**驱动。默认**只出语音**，
任何动作都必须先由操作员在本轮明确说「机器人已稳定站立、周围无遮挡，可以动作」。

| 步骤 | 指令（画布发送） | 机器人行为 |
|---|---|---|
| 1 开场 | `开始颁奖` | TTS 播报「颁奖典礼现在开始，请嘉宾就座，我们即将揭晓各个奖项。」 |
| 2 揭晓 | `揭晓：<奖项>，<获奖人>` | TTS 倒计时「三、二、一」→ 播报获奖人；安全确认后执行专属动作并鼓掌一次 |
| 3 庆祝 | `庆祝：<奖项>` | TTS 播报「恭喜获奖！」；本轮已确认时可再挥手一次 |
| 4 灯光 | `主题色：金/蓝/红` | 仅在本轮安全确认后调用 `led` 设置一次主题色 |
| 5 收尾 | `结束颁奖` | TTS 播报「颁奖典礼到此结束，感谢大家，明年再见。」 |

### 一键整场流程（奖项数量不固定）

整场不用逐条输入，用一条消息，**文本里有几个奖项就依次播报几个**（不再固定四个）：

```text
机器人已稳定站立、周围无遮挡，可以动作。一键颁奖：最佳创意奖=张三；最佳团队奖=李四；最佳新人奖=王五
```

对每个奖项按顺序执行：**面向观众 → 倒计时 → 播报获奖人 → 鼓掌 → 转向获奖者一侧 → 回头**，然后进入下一项；全部结束后播报谢幕。

- 鼓掌：**每次念完获奖人名字后必执行** `arm(action="execute", gesture="clap")`。
- 专属手势（可选）：按序号循环 `heart → high five → high wave → face wave → hands up`。
- 转向循环：`loco(action="move", vyaw=0.5, duration=3.0)` 转向、`loco(action="move", vyaw=-0.5, duration=3.0)` 转回，中间用 `loco(action="stop_move")` 收尾。

安全边界：只允许 `tts / arm / loco / led`；**转向属于行走类动作**，仅在本轮明确说「机器人已稳定站立、周围无遮挡，可以动作」时执行，未确认时跳过转向、只播报并鼓掌；禁止 `switch_mode / posture / smart_motion / mic / speaker / ASR / 相机 / OCR`，不得改变站立模式。

更完整的创意编排见 [`方案.md`](方案.md) 与 [`能力盘点与复合动作设计.md`](能力盘点与复合动作设计.md)。

## 二、推荐用法：确定性脚本（不经过大模型）

大模型读技能时顺序不稳定（会自己编奖项、漏掉转身/鼓掌），因此**推荐用脚本直接按固定顺序调用**：

```bash
# 真机上执行；每个奖项：念名字 -> 转身 -> 鼓掌 -> 转回
python3 ceremony_run.py "最佳创意奖=张三;最佳团队奖=李四;最佳新人奖=王五"

# 不动身体（只念名字 + 鼓掌）
python3 ceremony_run.py "最佳创意奖=张三;最佳团队奖=李四" --no-turn
```

奖项数量随文本而定，用 `;` 分隔 `奖项=获奖人`。参数 `TURN_RATE`（0.5 rad/s）、`TURN_TIME`（3.0s）可调转向幅度。

> 实机注意：`arm` 手势（如 `clap`）可能返回 `3104`/`740x` 等非零码，但**实测动作仍会执行**，以现场观察为准，不要因返回码跳过动作。`loco` 转身返回 `ret:0`。

## 三、在机器人上部署

```bash
# 1) 传入安装脚本（也可用 scp unitree@10.110.12.110:/tmp/）
base64 -i install_g1_award_ceremony.py | base64 -d   # 或直接 scp
# 2) 在真机上运行（会先自动备份 data.db）
python3 install_g1_award_ceremony.py
# 3) 重启核心容器以加载技能
cd /opt/phanthy-motus && docker compose restart agent-core
```

卸载：`python3 uninstall_g1_award_ceremony.py`（同样自动备份）。

## 三、验收 / 提交

1. 画布右上角「设计 ➡️ 技能」查看技能是否已安装，连接 `remote_message` + `agent_core` + `tts/arm/led` 卡片调试。
2. 测试通过后在 <https://motus.phanthy.com/zh/skills> 注册账号，在「技能 ➡️ 我的技能」创建并提交，找老师验收。
3. 验收时需带上对应机器人的 Master 一起。
